# Home

Your second brain starts here. Everything links back to this note.

## Operating System

- [[North Star]] — your goals and current focus
- [[Key Decisions]] — append-only log of decisions made
- [[Gotchas]] — mistakes captured so they never repeat
- [[Patterns]] — things that keep working
- [[Memories]] — durable long-term notes
- [[Skills]] — your tools and skills inventory

## Workspaces

| Folder | Purpose |
|---|---|
| `projects/` | One folder per active project |
| `wiki/concepts/` | Evergreen concept notes |
| `raw/` | Inbox — capture first, file later |
| `Templates/` | Note templates (Daily, Meeting) |
| `archive/` | Finished or dead projects |

## How to use this vault

1. Capture anything into `raw/` — don't organize while capturing.
2. Run `/om-dump` to route content to the right notes automatically.
3. Run `/om-wrap-up` at the end of a work session.
4. Run `/om-weekly` once a week to synthesize.
